# Python Assignments

This repository contains a collection of Python programming assignments created to practice fundamental programming concepts, problem-solving, and basic data handling.

## Programs Included

- **Fibonacci Generator** – Generates a sequence of Fibonacci numbers.
- **Basic Calculator** – Performs basic arithmetic operations such as addition, subtraction, multiplication, and division.
- **Dictionary Sorter** – Sorts the items in a dictionary based on their keys or values.
- **Factorial Calculator** – Calculates the factorial of a given number.
- **Grade Calculator** – Determines a student's grade based on their marks.
- **Palindrome Checker** – Checks whether a given word or string is a palindrome.
- **Prime Finder** – Checks and finds prime numbers.
- **Unique String Checker** – Checks whether all characters in a given string are unique.
- **Word Counter** – Counts the number of words in a given text.
